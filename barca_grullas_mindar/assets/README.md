# Assets

Coloca aquí el archivo de audio ambiente:

- `bosque_noche.mp3` — sonido de bosque/noche para acompañar la experiencia.

Si no lo colocas, el código intentará cargarlo desde el repositorio remoto de referencia. Si ambos fallan, la experiencia AR funciona igual, solo sin audio.

Puedes conseguir un audio libre de derechos de bosque nocturno y renombrarlo a `bosque_noche.mp3`.
