# Carpeta de objetivos (targets)

Aquí va el archivo **`targets.mind`** generado con el compilador de MindAR.

## Cómo generarlo

1. Toma una foto clara de La Barca de las Grullas o de su placa.
2. Ve a: https://hiukim.github.io/mind-ar-js-doc/tools/compile
3. Sube la imagen y descarga `targets.mind`.
4. Coloca el archivo aquí, en `targets/targets.mind`.

Sin este archivo la experiencia mostrará el mensaje "Falta targets/targets.mind".

## Recomendaciones para la imagen objetivo

- Alto contraste y detalles únicos (evita superficies lisas y repetitivas).
- Sin reflejos de vidrio ni sombras duras.
- La escultura debe ocupar la mayor parte del encuadre.
- Formato JPG o PNG, resolución de al menos 800 px de ancho.
- Si usas la placa, imprímela en mate.
